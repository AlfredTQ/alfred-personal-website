# Design system
Direction: Light Professional, corporate-clean with creative visual accent. White #FFFFFF, navy #14243D, blue #2563EB, body #1B2940, muted #63738A, soft background #F6F8FC. System UI font stack, preferring Inter if installed. Max content width 1200px, desktop gutters 42px, mobile 22px. Cards use restrained borders and 6–12px radii. Hero uses an abstract CSS illustration, not a fictional portrait. Use responsive breakpoints 950px and 650px. Respect reduced-motion preference and keyboard navigation. Keep claims evidence-grounded and distinguish pending credential verification.
